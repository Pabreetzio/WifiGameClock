# Next-generation hardware

This directory will contain the revived reference pod's schematics, PCB, BOM, and mechanical/enclosure work.

Historical Fritzing/breadboard work remains in [`../Hardware`](../Hardware).

The first hardware milestone should stay deliberately boring: a development board, readable `MM:SS` display, one large button, one status/RGB LED, and USB power. Prove the four-node networking and time-control architecture before committing to a custom PCB.
