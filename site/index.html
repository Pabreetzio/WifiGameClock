Wi‑Fi Game Clock is a modular game-timing platform. Give every player a clock pod, connect the pods wirelessly, and let software define what “the clock” means.

2 players

Run an ordinary chess clock without giving up the familiar physical button.

4-player bughouse

Put a clock beside every player and experiment with genuinely shared team time.

N players

Build timers for board games, tournaments, teams, handicaps, and rules nobody has named yet.

Hardware you can make yours

The reference pod starts simple: a readable four-digit display with a colon, a radio, and one satisfying button. From there the physical interface is intentionally hackable — illuminated arcade buttons, quiet switches, clicky switches, piezo controls, custom cases, RGB status lights, buzzers, speakers, or whatever fits the game.

No tiny-display programming ritual

Clock setup belongs on a screen designed for setup. Discover nearby pods from a phone, press a physical button to identify each player, choose a preset or create a time control, and start playing. The clocks then run locally; the phone and internet do not need to stay connected.

Time controls as software

A physical pod is a networked timer endpoint, not half of a permanently two-player chess clock. Logical clocks can belong to players or teams, multiple clocks can run simultaneously, and events can add, subtract, transfer, delay, or change the rate of time.

Built to keep evolving

The project is planned as a monorepo containing firmware, schematics, enclosure designs, the device web UI, a mobile companion, shared protocol/time-control libraries, and this project site. OTA updates make assembled clocks part of the development process instead of frozen prototypes.

Status

The original ESP8266 prototype already demonstrated a four-digit TM1637 display, button input, a hosted setup page, Wi‑Fi, mDNS, and clock-to-clock communication. The project is now being revived around a cleaner multi-device architecture, with a four-pod shared-time bughouse demo as the first reference target.
